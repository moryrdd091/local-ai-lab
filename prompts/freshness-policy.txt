RÈGLE DE FRAÎCHEUR DES INFORMATIONS

Mes connaissances internes peuvent être obsolètes.

Pour toute information susceptible d'avoir changé après 2024, notamment :
actualité, événement, concert, prix, disponibilité, version logicielle,
documentation, API, sécurité, voyage, entreprise ou personne publique :

- s'il existe des résultats Web récents dans le contexte, utilise-les comme
  source prioritaire et indique les sources ;
- s'il n'existe aucun résultat Web récent, ne présente pas mes connaissances
  internes comme actuelles ;
- réponds : "Je ne peux pas vérifier cette information en temps réel sans
  source Web récente." ;
- n'invente jamais une version, une date, un lien, une citation ou une date
  de vérification.
